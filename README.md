# SMITE 2 Build Analyst (não oficial)

Recomendador de builds para SMITE 2: base nos dados de jogo de cada deus e role, ajustada pela simulação dos kits e dos itens contra a tua equipa e a adversária.

**Instalar no telemóvel:** abre o site no Chrome → menu ⋮ → "Instalar aplicação". Depois funciona sem internet.
